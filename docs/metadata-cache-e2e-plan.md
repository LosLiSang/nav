# #10 / #12：实施前失败矩阵

用户已确认：公共图标、账号私有标题、普通用户受限批量刷新、管理员公共失效、
刷新失败保留旧值。确认设计不等于授权生产迁移、部署或清除缓存。

采用真实本地 Worker + 独立 D1 + 可计数的网络夹具；只替换 DNS 与出站网络，
不替换路由、会话、权限、缓存 SQL、租约、限流或前端状态。
夹具配置与入口在 `worker/test/`，生产入口不读取任何测试开关。

实现前运行并保留红灯报告。失败方式：

1. 首次 MISS 后第二次 HIT 仍抓取；不同 URL 或账号混用标题。
2. 查询串被重排、fragment 未归一；无登录标题进入持久化缓存。
3. 匿名 force、pending/disabled 或伪造书签越权刷新。
4. 缺失负缓存、过期/失败造成抓取风暴；刷新失败丢旧值。
5. 两个 Worker 共享 D1 时重复抓取；旧租约/旧代际晚返回覆盖新值。
6. 容量、响应大小、总时间、全局抓取并发及账号配额没有硬上限。
7. 私网 IP、编码 IP、IPv6、DNS 公转私、重定向公转私到达受保护上游。
8. DNS 校验和连接各自重新解析导致 rebinding；连接层必须限定公网目的地，
   HTTPS 使用原域名验证证书；不得转入私有 origin 或忽略 TLS 证书错误。
9. 普通用户批量超过 20 资源仍执行；管理员失效私有标题或业务表。
10. 批量部分失败无法只重试失败阶段；成功返回旧浏览器缓存；迟到本地请求回填。
11. 书签标题/手动图标/待同步数据被缓存操作修改；未同步书签绕过服务端归属校验。
12. 前端未连接新后端却显示成功；明暗/窄屏操作入口裁切或颜色不可读。

工件：JSON 检查报告、夹具出站计数、脱敏 SQL 摘要、明暗与窄屏截图。
不写新的单元测试；用可重复 E2E 验证路由与数据库实际行为。

## 本地代理连接：实现前失败矩阵

真实出站验证另行运行，不以夹具成功代替。使用现有 HTTP 代理，不修改系统配置：

1. 只设置 HTTP_PROXY，但 Workerd DNS/套接字仍然直连、超时。
2. CONNECT 使用目标域名而非已校验公网 IP，代理二次 DNS 解析引入 rebinding。
3. TLS 忽略证书或验证代理/IP 而非原域名，错误域名证书被接受。
4. CONNECT 非 200、超长响应、连接关闭或超时后仍发送目标请求。
5. HTTP/HTTPS、固定 DoH 解析、标题与图标的真实请求未被代理日志/工件证明。
6. 本地代理地址进入生产入口；本地服务或 UI 请求被错误代理。

工件包含真实 HTTP/HTTPS 结果、CONNECT 目标、证书错误拒绝结果和生产打包检查。
代理不可用必须失败，不自动直连；本地代理使用校验 IP 固定连接。

## 生产传输修正

原 Socket 方案无法作为受支持的 HTTPS 出站实现。改用 Cloudflare 原生 fetch，
明确开启 `global_fetch_strictly_public`：同区请求也从公网入口进入，不绕过访问控制，
不配置 private-origin/outbound/service 绑定。保留 DoH 地址过滤、逐跳重定向过滤、
无凭证请求和有界响应。防 rebinding 的最终边界是平台的公网出站限制，不再声称
DNS 预检等于连接 IP 固定。新增验收：真实 HTTPS 标题与图标 MISS/HIT；私网
解析域名、私网重定向、匿名强制刷新均拒绝；本地代理不进入生产包。
